# 退休咖深金品牌改版規格

## 已確認的目標
保留原站深藍與金色，重新設計品牌視覺、LOGO、七種工具與互動動畫，呈現成熟財務生活刊物的質感。所有原有內容、文章、工具、功能及網址完整保留。參考 Kinfolk 的編排與 Wealthsimple 的品牌層級，自行設計圖形，不複製品牌素材。

## 原站與保留範圍
- 基準為下載時的 main 分支；baseline-manifest.json 記錄原始版本與頁面、文章、共用功能檔案的 SHA256。
- content/articles 有 56 個 Markdown 檔案，含 about.md；全部逐字保留，不把此數量當作公開文章數。
- 七種工具：advanced-calculator、labor-insurance、fire-calculator、compound-interest、etf-dividend、couple-calculator、dca-vs-lumpsum。
- 首頁基本退休試算、全部輸入項目、輸出結果、資產配置及結果寄送完整保留。
- 文章列表、分類、文章內文、相關文章、作者與關於頁、FAQ、聯絡表單、隱私權與免責聲明完整保留。
- 書單、聯盟連結與揭露、廣告版位、訂閱、RSS、sitemap、SEO metadata 與 canonical 保留。
- 計算公式、預設數值、AI 分析功能、API、郵件及訂閱流程不改動。降低 AI 感是視覺調整，不刪除原有 AI 文字與功能。

## 配色與字體
保留 --bg #0a1622、--bg2 #0d1c2b、--panel #10202f、--panel2 #13273a、--gold #d4a95a、--gold2 #ecc776、--cream #f3ecdd，以及原有語意色。既有 Noto Sans TC、Noto Serif TC 與 Space Mono 沿用；襯線字用在品牌及主標題，無襯線字用在操作與長文，數字採等寬數字。正文至少 16px、行高約 1.8。

## LOGO
中文字標搭配自行繪製的咖啡杯／地平線向量標記。杯口水平線結合低弧形日出，杯身保留簡潔輪廓，避免盾牌、上升箭頭及金色光暈。建立共用 BrandLogo 元件，所有原有導覽的品牌入口一致使用；保留各頁原有導覽連結。favicon 使用同一標記，確認 16–32px 可辨識。

## 首頁構圖
桌機首屏使用左右構圖：左側完整保留原有主標題、描述與兩個入口，右側用原創杯形與日出線條構成品牌主視覺。移除星空粒子、滑鼠追蹤、掃光與持續發光效果。窄螢幕改單欄，主視覺不推遲主要操作。首頁工具、基本試算、文章、書單、廣告與頁尾全部保留。

## 七種工具呈現
桌機三欄，主工具佔兩列；六種次要工具中，最後的雙策略比較橫跨兩欄，用以容納較長標題並與底列的夫妻工具對齊，避免留下空格。平板兩欄、手機單欄，七種直接可見，不使用隱藏輪播。保留標題、描述、徽章與原有連結。取代 emoji 的圖形對應如下：
1. 進階退休試算：時間刻度與目標弧線。
2. 勞保年金：固定週期刻度。
3. FIRE：到達地平線的路徑。
4. 複利成長：細線複利曲線。
5. ETF 配息：分期分配柱形。
6. 夫妻退休：兩條並行軌跡。
7. 定期定額 vs 單筆：两種投入路徑。
所有图形為裝飾性向量圖，標記 aria-hidden，不顯示虛構金額或真實試算預覽。工具列表頁使用相同圖形系統，各工具內頁保持全部操作與結果並統一閱讀與表單視覺。

## 動畫與操作
按鈕箭頭及邊線過渡約 180–240ms，卡片圖形只在 hover 或 focus-within 時短暫變化。進場動畫淡入與位移不超過 12px，約 450ms，一次播放；未啟用 JavaScript 時內容仍可見。試算結果取消彈跳，以輕微淡入過渡呈現，顯示數字仍為原公式結果。觸控不依賴 hover。尊重 prefers-reduced-motion，關閉位移、繪線與平滑捲動，保留鍵盤焦點與所有操作。

## 實作邊界
沿用 Next.js 14 Pages Router 與現有 React，不新增大型動畫套件。主要新增 BrandLogo、ToolArtwork、ToolCollection 共用元件與工具展示資料，修改首頁、工具列表、各頁品牌入口、試算器動畫與共用 CSS。文章內容、lib 計算函式與 API 不修改。保留各工具原有狀態、事件與圖表資料。

## 驗收
1. 建置成功，確認所有原有頁面檔案仍存在，56 個內容檔案的 SHA256 全部相同，API 與計算核心沒有變更。
2. 七種工具逐一可進入、調整輸入、看到結果；代表性輸入在改版前後結果相同。
3. 首頁基本試算、文章分類、文章頁與相關文章、書單與頁尾連結可用。
4. 390px、768px、1440px 版面無整頁水平溢出；長表格與圖表維持局部捲動。
5. 鍵盤可操作入口、表單與選單，焦點清楚；減少動畫設定生效。
6. 郵件與訂閱端點保留；未提供郵件服務設定時不發送真實郵件，交付時明確標記未完成外部服務驗證。
7. 提供本地預覽；本次先完成可審閱版本，正式上線另行執行。
