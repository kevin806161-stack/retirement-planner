## 使用與限制
本機預覽：http://localhost:3017/ 。網站在本機背景執行；如果程序停止，可於專案資料夾執行 `npm run start -- --port 3017`。重新修改網站後須先執行 `npm run build`。

原有郵件、聯絡、訂閱端點保留。未提供本機服務設定，也未實際寄送信件、送出聯絡訊息或新增訂閱；外部服務成功送達尚未驗證。

本次改動儲存在本地 redesign/dark-gold-editorial 分支，未推送 GitHub，未變更正式網站。
